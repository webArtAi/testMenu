# Дружба — инструкция для пользователя

Меню редактируется в `menu.xlsx`. После загрузки файлов на GitHub сайт обновляет GitHub Actions. На компьютере достаточно Excel и браузера.

Полная инструкция с наглядными схемами находится в файлах **ИНСТРУКЦИЯ.pdf** и **ИНСТРУКЦИЯ.html** из комплекта обновления. Эти документы сохраняются на компьютере.

## Обновить сайт

1. Скачайте актуальный `menu.xlsx` из своего репозитория и откройте в Excel.
2. Внесите изменения и сохраните файл под именем `menu.xlsx`.
3. Новые фотографии сначала загрузите в `photos`, новый фон — в `assets`. Подтвердите **Commit changes**.
4. Обновлённый `menu.xlsx` загрузите в корень репозитория, заменив прежний. Подтвердите **Commit changes**.
5. Откройте **Actions**, дождитесь зелёной галочки у последнего запуска, затем обновите страницу сайта.

Для изменения только текста или цены достаточно загрузить `menu.xlsx`. Если последняя сборка завершилась ошибкой, предыдущая опубликованная версия продолжает работать.

## Изменить блюдо

Лист **Меню**:

| Колонка | Значение |
|---|---|
| A — Раздел | Выбор категории из списка |
| B — Название блюда | Название карточки |
| C — Порция / вариант | Вес, объём или размер |
| D — Цена | Число без ₽ |
| E — Описание / состав | Текст карточки |
| F — Фото | Только имя файла из `photos`, например `new-dish.jpg` |
| G — Показывать | Да / Нет |
| H — Код | У существующего блюда сохраняйте; у нового оставляйте пустым |
| I — Бонус к блюду | Бонус только к этой карточке; пусто — бонуса нет |

Новая карточка: скопируйте основную строку блюда с названием и вставьте **скопированные ячейки** после всех порций предыдущего блюда. Замените поля, очистите H; очистите I, если бонуса нет. Дополнительная порция идёт сразу под блюдом: заполнены только C и D.

Перемещайте блюдо вместе со всеми его порциями. Обычная сортировка отдельных строк разъединит их. Формулы в ячейках не используются.

## Заменить фото

1. Сохраните новое фото под новым именем, например `new-photo.jpg`.
2. Загрузите его в `photos` и подтвердите **Commit changes**.
3. В Excel у нужного блюда замените имя в F на `new-photo.jpg`.
4. Сохраните и загрузите `menu.xlsx` в корень репозитория.

Поддерживаются JPG, PNG и WebP. Имя в F должно совпадать с файлом целиком, включая расширение. Переименование `.jpg` в `.webp` не конвертирует изображение. Сборщик сам подготовит WebP для сайта.

Фотографии размещаются в рамке 4:3. Выбирайте снимок, где предмет крупный и помещается целиком. Подобранное для прежнего фото приближение не переносится на другой снимок автоматически. В подробностях показывается полный исходный кадр.

Две карточки комплексного обеда редактируются отдельно. Сейчас они используют одинаковое фото; для отдельной замены укажите новое имя файла только у нужной строки.

## Добавить категорию

1. Откройте лист **Разделы** и выберите последнюю ячейку таблицы.
2. Нажмите **Tab** — добавится новая строка таблицы.
3. Введите название категории.
4. На листе **Меню** выберите её в A у нового или существующего блюда.
5. Сохраните и загрузите `menu.xlsx`.

Список в A расширяется вместе с таблицей. Раздел появляется на сайте, когда в нём есть хотя бы одно блюдо с **Показывать: Да**. Порядок разделов соответствует порядку строк на листе **Разделы**.

## Изменить фон

Лист **Настройки**, строка **Тип фона**:

| Тип | Что заполнить |
|---|---|
| Картинка | Загрузите один JPG, PNG или WebP в `assets`. В строке **Фон** укажите его имя |
| Цвет | Выберите значение в строке **Цвет фона** |
| Градиент | Выберите **Градиент: цвет 1**, **Градиент: цвет 2**, **Градиент: направление** |

Цвет выбирается из списка: тёмно-коричневый, чёрный, тёмно-зелёный, тёмно-синий, бордовый, серый, бежевый, белый. Для своего цвета можно ввести `#RRGGBB`, например `#21160E`. Серые ячейки в Excel относятся к другому типу фона и сейчас не используются.

Для нового изображения сборщик подготовит размеры для компьютера и телефона. Исходный файл в репозитории сохраняется. Текущий фон и оформление при установке обновления остаются прежними.

## Другие настройки

На листе **Настройки** находятся название кафе, контакты, тексты и **Telegram URL**. На листе **Ссылки** — подписи и настоящие HTTPS-адреса.

**Предварительная версия: Да** сохраняет запрет поисковой индексации. Это не защита доступа: сайт открывается по ссылке. После проверки данных можно выбрать Нет и указать настоящий **Сайт URL** для sitemap/canonical.

## Для разработчика

Python 3.12, openpyxl, Pillow. Готовый HTML создаётся из `templates/index.html`; весь CSS и JavaScript находятся в проекте. Пользователю не нужны Node.js, токены или отдельный редактор.

```sh
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
python build.py
```

Результат — `site/`. Сборка сначала проверяет данные и готовит новый результат отдельно; при ошибке предыдущая версия не заменяется. GitHub Pages публикуется официальным workflow `.github/workflows/pages.yml` из ветки `main`; в Settings → Pages должен быть выбран **GitHub Actions**.

Диапазон `MenuSections` ссылается на столбец `MenuCategories[Раздел]` таблицы Excel. Изображения фона получают размеры 1800/900 пикселей по ширине без увеличения маленьких исходников. Прежняя пара изображений фона сохраняется побайтово, пока оба исходника совпадают с опубликованными оригиналами. Старые таблицы без новых настроек фона поддерживаются.

Индивидуальные кадры блюд хранятся в `photo-framing.json` и привязаны к исходным фото. Сохраняйте этот файл вместе с проектом; пользователю не требуется редактировать его вручную.
